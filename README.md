# aws-static-portfolio-website
## Project Description
A static portfolio website created using HTML, CSS and JavaScript and hosted on Amazon S3. This project demonstrates how to deploy a static website on AWS using Amazon S3. The portfolio contains information about my skills, education, internship experience, certifications, and projects.


## AWS Services
- Amazon S3
- S3 Static Website Hosting

## Technologies
- HTML5
- CSS3
- JavaScript
- Amazon S3
- S3 Static Website Hosting

## Deployment
Amazon S3
Created an S3 bucket
Uploaded website files
Enabled Static Website Hosting
Configured public access
Configured bucket policy for website access

The website is deployed using Amazon S3 Static Website Hosting.
http://my-portfolio-website-pallavi.s3-website.eu-north-1.amazonaws.com/
